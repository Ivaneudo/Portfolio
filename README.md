# Portfólio Pessoal (v1.0) 🚀

Bem-vindo ao repositório da primeira versão do meu portfólio profissional! Este projeto foi desenvolvido para apresentar meus projetos, habilidades e trajetórias na área de desenvolvimento de software.

🔗 **Acesse o portfólio online:** [Portfolio](https://ivaneudo-portfolio.vercel.app/) 

> ⚠️ **Nota da versão (v1.0):** Esta é a primeira versão do site e atualmente está **otimizada apenas para visualização no computador (desktop)**. A versão responsiva para dispositivos móveis está em desenvolvimento para as próximas atualizações!

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando o ecossistema React com tipagem estática e estilização baseada em componentes:

- **[React](https://react.dev/):** Biblioteca principal para a construção da interface.
- **[TypeScript](https://www.typescriptlang.org/):** Tipagem estática para maior segurança e produtividade no código.
- **[Emotion JS](https://emotion.sh/):** Biblioteca CSS-in-JS para estilização dinâmica e escopada de componentes.

## 🚀 Como executar o projeto localmente

Caso queira clonar e explorar o código-fonte na sua máquina:

1. Clone o repositório:

```bash
  git clone https://github.com/Ivaneudo/Portfolio.git
```

Entre na pasta do projeto:

```Bash
  cd Portfolio
```
Instale as dependências:

```Bash
  npm install --legacy-peer-deps
  # ou
  yarn install
```
Inicie o servidor de desenvolvimento:

```Bash
  npm run dev
# ou
  yarn dev
```

Abra o navegador em http://localhost:5173 (ou a porta indicada no terminal).
